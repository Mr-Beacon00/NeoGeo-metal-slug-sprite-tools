# NeoGeo-metal-slug-sprite-tools
Convert sprite in C rom / S rom from Neo Geo version Metal Slug series.

Convert non-encrypted sprite rom to TiledGGD readable format.

Code is generated by AI.

Also thanks to NeoGeo Development Wiki.<br />
[Reference 1](https://wiki.neogeodev.org/index.php?title=Sprite_graphics_format)<br />
[Reference 2](https://wiki.neogeodev.org/index.php?title=Fix_graphics_format)

## Usage
Convert C rom (sprite).
```
crom_convert.exe <input_odd_number_c.bin> <input_even_number_c.bin> <output_name>
```

Convert S rom (FIX layer).
```
srom_convert.exe <input_s.bin> <output_name>
```
## Example
```
crom_convert.exe 201-c1.bin 201-c2.bin 201_output1.bin
```
```
crom_convert.exe 201-c3.bin 201-c4.bin 201_output2.bin
```
```
srom_convert.exe 201-s1.bin 201_outputFIX.bin
```

# Palette note
Metal Slug 2 and later, you can found RGB palette in p file. (maybe color pool still in there)<br />

But Metal Slug 1 is use color pool (is that how it called?)<br />
and need to rearrange to get palette.

In p file's 0x00102f30 ~ 0x00112f2f range, you can found color pool.
color pool contain every color.

In p file's 0x00114e00 ~ 0x00124dff range you can found index file.
index can rearrange color pool's color and generate palette file.

## Usage

Combine index file and color pool file together to create a palette file
```
create_pal.exe <input_index_file> <input_color_pool_file> <output_name>
```
